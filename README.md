# REMIX 스밍 위젯

매 정각(00분 00초)에 1번 곡이 시작된다고 보고, 지금 틀어야 할 곡을 홈 화면 위젯에 보여 주는 안드로이드 앱입니다.

- 현재 재생 위치(크게)와 곡 종료까지 남은 시간이 **시스템 타이머**로 매초 올라가고 내려갑니다.
- 곡이 바뀌는 시각에 알람으로 위젯을 다시 그립니다. 시작 버튼이나 설정이 필요 없습니다.
- 위젯은 두 가지입니다: **REMIX 스밍 (작게)**, **REMIX 스밍 (목록 포함)** (전체 목록에서 지금 곡 강조).
- LockStar(Good Lock)로 잠금화면에도 올릴 수 있습니다.

## 목록을 바꾸면 다른 사람도 바뀌게 하는 방법

곡 목록은 앱 안에 박혀 있지 않고 저장소의 `list.json` 파일에 있습니다.

1. GitHub 저장소에서 `list.json` 을 수정하고 저장(Commit)합니다.
2. 다른 사람은 앱을 열고 **목록 새로고침** 을 누르면 바뀐 목록을 받습니다. (앱을 열 때 마지막 새로고침이 1시간 이상 지났으면 자동으로도 받습니다.)
3. 앱 자체(디자인, 기능)를 고쳤을 때는 **새 버전 앱 받기** 를 눌러 APK 를 다시 내려받아 설치하면 됩니다. 이미 설치된 앱 위에 덮어써지고 목록은 유지됩니다.

### list.json 형식

```json
{
 "name": "HYPERDRIVE REMIX",
 "version": "2026-11-10",
 "cycleSeconds": 3600,
 "tracks": [
  { "title": "Star Trace", "sub": "", "length": "2:59" },
  { "title": "Star Trace", "sub": "Future House Remix by jeonghyeon", "length": "2:44" }
 ]
}
```

- `title` 곡명, `sub` 부제(리믹스 정보 등, 없으면 `""`), `length` 곡 길이 `"분:초"` (초로 쓰려면 `"seconds": 179`)
- `cycleSeconds` 는 한 바퀴 길이로 보통 `3600` (정각마다 1번 곡부터 다시 시작)
- 곡 총 길이가 3600초를 넘으면 정각에 마지막 곡이 잘리고, 모자라면 마지막 곡 뒤에 다음 정각까지 "대기" 상태가 됩니다.
- 곡은 최대 30곡까지 큰 위젯에 보입니다.
- 형식이 틀린 목록은 앱이 받지 않고 기존 목록을 그대로 씁니다. (앱의 새로고침 실패 메시지에 이유가 나옵니다.)

## 설치 (사용자)

1. 휴대폰 브라우저에서 `https://github.com/OWNER/REPO/releases/latest/download/RemixWidget.apk` 를 열어 내려받습니다.
2. 설치할 때 "출처를 알 수 없는 앱" 허용을 묻는 창이 나오면 허용합니다.
3. 홈 화면을 길게 눌러 위젯 → **REMIX 스밍** 을 추가합니다.
4. 곡이 바뀌는 순간이 늦으면 앱을 열어 **정확한 알람 허용하기** 를 누르고 허용합니다.
5. 설정 → 앱 → REMIX 스밍 → 배터리를 **제한 없음** 으로 두면 알람이 덜 밀립니다.
6. 폰의 날짜 및 시간은 **자동** 으로 둡니다.

## 만들기 (운영자: 처음 한 번)

1. GitHub 에 **공개(Public)** 저장소를 만들고 이 프로젝트 파일을 올립니다.
2. `app/build.gradle` 의 `pozia-cyber`, `Streaming-widget` 두 곳을 본인 GitHub 아이디와 저장소 이름으로 바꿉니다.
3. `main` 에 올리면 Actions 가 자동으로 APK 를 만들어 **Releases → latest** 에 `RemixWidget.apk` 로 올립니다. (Actions 탭의 "Build APK" 를 직접 실행해도 됩니다.)
4. 위 설치 주소를 다른 사람에게 보내면 됩니다.

PC 에서 직접 만들려면 Android Studio 로 이 폴더를 열고 **Build → Build APK(s)** 를 실행합니다.

## 알아 둘 점

- `app/shared.keystore` 는 업데이트 설치가 되도록 매번 같은 서명을 쓰기 위한 개인용 키입니다. 공개 저장소에 올라가므로 앱 스토어 배포용으로는 쓰지 마세요.
- 곡 길이는 이미지 기준 시간이라 실제 재생과 1~2초 어긋날 수 있습니다.
- 초 단위 타이머는 시스템이 세기 때문에 위젯 갱신과 상관없이 올라가지만, 곡이 바뀌는 순간의 화면 교체는 알람 시각에 달려 있습니다.
